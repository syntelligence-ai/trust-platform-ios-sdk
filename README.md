# Trust Platform iOS SDK

Swift Package Manager distribution of the Trust Platform iOS SDK. The `TrustPlatform` and
`TrustPlatformUI` products are precompiled binary frameworks, hosted on Syntelligence's SDK
CDN and referenced by checksum from `Package.swift`.

Each tag is a released version. The manifest here is written by the Release workflow in the
SDK's source repository; it is not edited by hand.

Integration instructions are in the [SDK documentation](https://syntelligence.ai).
